## Collaborative working

The group agreed on 7 November 2026 that these roles are leads for coordination rather than exclusive responsibilities.

All members are expected to contribute to reviewing requirements, developing and testing the application, identifying improvements and documenting their learning.

Development activities will proceed in parallel, with regular communication through Microsoft Teams.

## GitHub workflow

1. Clone the shared `travel-agent-records` repository.
2. Fetch the latest changes before starting work.
3. Develop on a separate branch rather than `main`.
4. Run and test changes locally.
5. Commit changes using the required PyInstaller commit-message convention.
6. Push the branch to GitHub.
7. Open a pull request for peer review before merging into `main`.
